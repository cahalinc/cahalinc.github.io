biolab_UI

Experiment OS（Bio Lab OS）

実験の設計 → 検証 → 人の承認 → 実行 → 解析 → 次実験提案までをブラウザで回す Experiment OS。実機なしでもシミュレータで end-to-end デモが動く、Cloud Lab / EaaS の技術基盤です。

  • AI Designer / Validator / Human approval
  • Simulator Run + リアルタイムイベント
  • AI Analyzer → 最適条件と次実験提案
  • FastAPI + Postgres + Redis + プロトコル検証
SNS Content Studio
biospatial

BioSpatial OS

安価な RGB-D と自然言語プロトコルから、ティーチングなしのピック＆プレースを目指す空間認識ミドルウェア。見て・計画し・失敗したら再観測してリトライするクローズドループが中核です。

  • 「96ウェルプレートを遠心機へ」を端到端デモ
  • 6DoF 姿勢推定 · look-then-move · 自動リトライ
  • 監査ログ付き · PyBullet / Isaac Sim 両対応設計
