見て、掴んで、置き直す — BioSpatial OS

2026年 元リポジトリ: biospatial（OSS）

当社が公開している OSS の説明です。他社のロボティクス論文を自社実験成果として掲載するものではありません。コードは GitHub で確認できます。

BioSpatial OS は、既存のベンチと汎用アームの上に載せるミドルウェアだ。自然言語のプロトコルと安価な RGB-D から、教示なしのピック＆プレースを目指す。失敗したら再観測してやり直す。その前提で設計している。

いまの MVP がやること

垂直スライスは一本だけだ。

「96ウェルプレートを掴んで、遠心機に置く。」

点群から 6DoF を出し、動作計画し、把持を確認し、置けたら検証する。ここまでをシミュレーション上で通す。

なぜこの切り方か

最終的には Isaac Sim や FoundationPose、SAM 2、ROS 2 / MoveIt 2 などを想定している。ただし MVP は Apple Silicon の Mac でも今日動くように、重い部品は差し替え可能なインタフェースの後ろに置いた。点群の扱い、6DoF、タスクグラフ、/tf 契約など、プロバイダに依存しない部分は本番でもそのまま持っていくつもりだ。

Loop のどこに効くか

手順が正しくても、腕がプレートを落とすとループは止まる。空間側の再試行があることで、「計算と実験」のあいだにある物理の失敗を、同じシステム内で扱えるようになる。
