Product 01 公開中

手順 RAG

対象：生命科学者・熟練研究者

IFU / SOP / 文献から実験手法を裏取りする手順検索プロダクト。出典突合・チェックデモ・ログイン後の自由検索までを提供します。

  • 正しい手法を検索・照合できることが第一の価値
  • 公開アプリとして運用中
  • 体験ゲームとも連携

Product 02 デモ可

Experiment OS

対象：ラボ運営・共同研究・EaaS 検討

実験の設計 → 検証 → 人の承認 → 実行 → 解析 → 次実験提案までをブラウザで回す実験OS。実機なしでもシミュレータで end-to-end デモが可能です。

  • AI Designer / Validator / Human-in-the-loop
  • Simulator Run とリアルタイムイベント
  • Cloud Lab / Experiment-as-a-Service の基盤

Product 03 OSS

BioSpatial OS

対象：ラボ自動化・Physical AI 検証

自然言語の指示と RGB-D から、ティーチングなしのピック＆プレースを目指す空間認識ミドルウェア。失敗時は再観測して自動リトライします。

  • 「プレートを遠心機へ」端到端デモ
  • 6DoF 姿勢推定 · look-then-move
  • 監査ログ付き · ノートPCでも再現可
GitHub で見る 導入相談
