Experiment OS

設計 → 検証 → 人の承認 → 実行 → 解析 → 次実験提案までをブラウザで回す実験OS。実機なしでもシミュレータで一連の流れを見せられます。バイオインフォ受託の実行面の土台です。

対象：ラボ運営・共同研究・EaaS 検討

デモ相談 背景メモ バイオインフォ受託 関連ツール
Product 03OSS

BioSpatial OS

自然言語の指示と RGB-D から、ティーチングなしのピック＆プレースを目指す空間認識ミドルウェア。失敗時は再観測して自動でやり直します。現在はシミュレーション（PyBullet / Isaac Sim）で検証しており、実機での検証はこれからです。ラボ自動化受託の中核です。

対象：ラボ自動化・空間認識の検証

GitHub 背景メモ ラボ自動化受託 導入相談
